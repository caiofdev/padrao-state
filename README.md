# Padrão State

Implementação do padrão State para controlar as transições de estado de um aluno.
As classes pertencem ao pacote `com.example.state`.

## Requisitos

- JDK 17 ou superior
- Maven 3.9 ou superior

## Executar os testes

```bash
mvn test
```

## Empacotar

```bash
mvn package
```

Este projeto não possui uma classe `main`; seu comportamento é validado pelos
testes automatizados.
